# 🌟 **Coiniko** - Your Gateway to Cryptocurrencies 🌍

**Coiniko** is an interactive platform designed to provide real-time cryptocurrency data. 💰📈 With a user-friendly interface, Coiniko delivers accurate information on prices, changes, volumes, and more! 🚀

---

## 📋 **Features**
- 🔍 **Dynamic Search**: Quickly find information about your favorite cryptocurrencies.
- 📊 **Real-Time Data**: Stay updated with prices, market caps, and volumes directly from the CoinMarketCap API.
- 🌙 **Light/Dark Mode**: Switch between light and dark modes for a comfortable browsing experience.

---

## 🛠️ **Technologies Used**
- **Next.js** for a fast and responsive interface.
- **Tailwind CSS** for modern and customizable styling.
- **CoinMarketCap API** for reliable cryptocurrency data.
